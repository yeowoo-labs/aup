# 보안 공지

aup의 보안 결함을 고친 뒤의 요약이다. 공지마다 고친 커밋, 영향을 받는 판, 회귀 시험을 적는다. 결함을 잠그는 시험은 이 저장소의
`tests/check.py`에 있다. 공지 번호는 Pure·aup·Vega가 함께 쓴다(Pure의 공지는 Pure 저장소의 `docs/security/`에 있다).
